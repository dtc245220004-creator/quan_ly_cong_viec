# Triển khai hệ thống Quản lý công việc (Task Tracker)
## Yêu cầu hệ thống
- Docker & Docker Compose
## Cách chạy hệ thống
1. Clone repository này.
2. Chạy lệnh: `docker-compose up -d --build`
## Truy cập các dịch vụ:
- **Ứng dụng Web (Nginx Proxy):** http://localhost (Port 80)
- **pgAdmin:** http://localhost:5050 (admin@admin.com / StrongPassword123!)
- **Grafana:** http://localhost:3000 (admin / admin)
- **Prometheus:** http://localhost:9090
